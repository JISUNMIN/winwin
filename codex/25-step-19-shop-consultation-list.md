# 25. Step 19 샵 상담 목록 화면

## 목표

샵 채팅 화면으로 들어가는 실제 진입 화면을 만듭니다.

이전에는 `/shop/chat/[id]` 라우트가 있어도 들어가는 입구가 약했고, 매칭 상세에서 바로 샵 채팅 미리보기만 여는 수준이었습니다.

이번에는 `/shop` 목록 화면을 추가해서 샵이 상담 상태를 보고 각 채팅으로 들어갈 수 있게 만들었습니다.

## 만든 파일

```text
src/app/shop/index.tsx
```

## 수정한 파일

```text
src/app/matching/[id].tsx
```

## 새로 만든 화면

`/shop` 화면에는 아래 요소가 들어갑니다.

- 샵 상담 목록 제목과 설명
- 진행 중 상담 수 / 결제 대기 수 요약 카드
- 상담 상태별 카드 리스트
- 카드 클릭 시 `/shop/chat/[id]` 이동

## 카드에 들어가는 정보

각 상담 카드에는:

- 샵 이름
- 서비스명
- 상태 배지
- 다음 가능한 날짜
- 현재 상담 요약 문구

가 표시됩니다.

상태는 현재 mock 데이터로 아래처럼 표현했습니다.

- `검토중`
- `결제대기`
- `확정`

## 상세 화면 연결 변경

매칭 상세 하단의 보조 버튼도 이제 샵 채팅 미리보기 대신 `샵 상담 목록`으로 들어가도록 바꿨습니다.

즉 흐름이:

```text
매칭 상세
-> 샵 상담 목록
-> 특정 상담 카드 선택
-> 샵 채팅 화면
```

으로 조금 더 자연스러워졌습니다.

## 왜 이 단계가 중요한지

샵 입장에서는 보통 채팅 하나만 단독으로 보는 것이 아니라, 여러 상담을 목록에서 확인한 뒤 상태별로 관리합니다.

이번 화면은 이후:

- 상담 상태 필터
- 정렬
- 읽지 않은 메시지 표시
- 예약 확정/결제대기 분류

같은 관리자 기능으로 확장하기 좋은 시작점입니다.

## React 개발자 기준으로 보면

- `/shop` 화면은 웹의 관리자 리스트 페이지 하나를 만든 것과 비슷합니다.
- RN의 화면 파일도 결국 라우트 단위 React 컴포넌트라서, `src/app/shop/index.tsx`가 페이지 컴포넌트 역할을 합니다.
- 카드 클릭으로 다른 라우트로 이동하는 흐름은 웹의 목록 페이지에서 상세 페이지로 `navigate`하는 패턴과 거의 같습니다.

## 핵심 로직

- 상담 카드 리스트는 mock 데이터 배열을 `.map(...)`으로 순회하면서 렌더링합니다.
- 각 카드의 `onPress`에서 `/shop/chat/[id]`로 이동할 `id`를 넘겨줍니다.
- 매칭 상세 화면의 보조 버튼도 이제 이 리스트 화면으로 먼저 보내도록 바꿔서, 샵 사용자 동선을 목록 중심으로 정리했습니다.

## 핵심 코드

```ts
onPress={() =>
  router.push({
    pathname: '/shop/chat/[id]',
    params: { id: item.matching.id },
  })
}
```

상담 카드 하나를 누르면 해당 매칭 id로 샵 채팅 라우트에 진입합니다.
