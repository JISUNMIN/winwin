# 32. Step 26 샵 공고 관리 목록

## 목표

샵 상담 목록 안에 섞여 있던 등록 공고를 별도 관리 화면으로 분리합니다.

이번 단계에서는:

- `/shop/post` 관리 화면 추가
- 등록 공고 목록 모아보기
- 샵 홈에서 관리 화면 진입 연결

까지 정리했습니다.

## 수정한 파일

```text
src/app/shop/index.tsx
src/app/shop/post/index.tsx
codex/README.md
codex/progress-and-next-steps.md
```

## 1. 공고 관리 화면 추가

새 화면:

```text
/shop/post
```

를 만들었습니다.

여기서 샵은 등록한 공고 개수, 위치 공개 방식, 다음 가능 날짜, 보증금을 한 번에 볼 수 있습니다.

각 카드에서 매칭 상세 화면으로도 바로 이동할 수 있습니다.

## 2. 샵 홈은 상담 중심으로 유지

기존 `/shop` 화면에는 `내가 등록한 공고`가 길게 같이 붙어 있었는데, 이제는 일부만 미리 보여주고 `전체 보기`로 관리 화면에 들어가도록 바꿨습니다.

즉:

```text
샵 홈
-> 상담 목록 중심
-> 등록 공고는 요약 미리보기
-> 전체 관리는 /shop/post
```

구조가 됐습니다.

## 3. 빈 상태도 준비

등록한 공고가 아직 없을 때는 빈 상태 카드와 `첫 공고 등록하기` 버튼이 보이도록 했습니다.

그래서 공고 관리 화면을 먼저 열어도 막막하지 않게 시작할 수 있습니다.

## React 개발자 기준으로 보면

- `/shop/post`는 웹의 관리자 "내가 만든 게시물 목록" 페이지와 같은 역할입니다.
- RN 화면도 결국 React 컴포넌트라서, `useIsFocused()`로 화면 재진입 시 데이터를 다시 읽어오는 패턴을 사용했습니다.
- 빈 상태 렌더링은 웹에서 `posts.length === 0 ? EmptyState : List`로 처리하는 방식과 같습니다.

## 핵심 로직

- 관리 화면은 `getPostedMatchings()`를 읽어서 등록 공고 배열을 가져옵니다.
- 화면이 다시 포커스될 때마다 같은 함수를 다시 호출해서 최신 공고 목록을 반영합니다.
- 공고 카드 클릭은 상세 화면으로, `새 공고 등록` 버튼은 등록 폼 화면으로 각각 라우팅합니다.

## 핵심 코드

```ts
useEffect(() => {
  if (isFocused) {
    setPostedMatchings(getPostedMatchings());
  }
}, [isFocused]);
```

공고 관리 화면으로 다시 돌아왔을 때도 최신 공고 배열을 다시 읽어서 목록을 갱신합니다.
