# 14. Step 8 채팅 화면 만들기

## 목표

상세 화면의 하단 `지원하기` 버튼을 누르면 채팅 화면으로 이동하게 만듭니다.

## 만든 파일

```text
src/app/chat/[id].tsx
```

Expo Router에서 이 파일은 아래 같은 주소를 처리합니다.

```text
/chat/1
/chat/2
/chat/abc
```

여기서 마지막 값이 `id`입니다.

## 상세 화면에서 채팅으로 이동

`src/app/matching/[id].tsx`의 하단 버튼에 `onPress`를 추가했습니다.

```tsx
router.push({
  pathname: '/chat/[id]',
  params: { id: matching.id },
})
```

React 웹으로 비유하면 `navigate('/chat/1')`와 비슷합니다.

## 채팅 화면에서 한 일

채팅 화면에는 아래 요소를 넣었습니다.

- 뒤로가기 버튼
- 매장 이미지
- 매장 이름
- 서비스 이름
- 기본 상담 메시지
- 사용자가 보낸 메시지 말풍선
- 매장 자동 답장 말풍선
- 메시지 입력창
- 전송 버튼

## RN에서 웹과 다른 점

웹에서는 보통 `div`, `input`, `button`을 씁니다.

RN에서는 아래 컴포넌트를 사용했습니다.

```text
View       -> div 역할
Text       -> 텍스트 표시
TextInput  -> input 역할
Pressable  -> button 역할
ScrollView -> 스크롤 영역
```

메시지 입력창이 키보드에 가려지는 것을 줄이기 위해 `KeyboardAvoidingView`도 사용했습니다.

## 이번 단계에서 아직 하지 않은 것

디자인 원본에는 사진 첨부, 예약 날짜 선택, 보증금 결제 모달이 있습니다.

이번 단계에서는 처음 RN 흐름을 익히기 위해 채팅 진입과 메시지 전송까지만 만들었습니다.

이후에 아래 순서로 하나씩 붙일 수 있습니다.

```text
1. 사진 첨부 버튼 동작
2. 예약 날짜 선택 UI
3. 예약 요청 카드
4. 보증금 결제 모달
```

## 직접 확인 방법

1. Home 화면에서 매칭 카드의 `지원하기`를 누릅니다.
2. 매칭 상세 화면으로 이동합니다.
3. 상세 화면 하단의 `지원하기`를 누릅니다.
4. 채팅 화면으로 이동하는지 확인합니다.
5. 메시지를 입력하고 전송 버튼을 눌러 말풍선이 추가되는지 확인합니다.
