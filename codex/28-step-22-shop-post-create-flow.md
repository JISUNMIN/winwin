# 28. Step 22 샵 공고 등록 기본 흐름

## 목표

샵/사장님이 직접 공고를 올릴 수 있는 기본 등록 흐름을 만듭니다.

이번 단계에서는 실제 저장까지는 하지 않고:

```text
샵 상담 목록
-> 새 공고 등록
-> 입력 폼 작성
-> 등록 완료 화면
```

흐름을 먼저 완성했습니다.

## 만든 파일

```text
src/app/shop/post/new.tsx
src/app/shop/post/created.tsx
```

## 수정한 파일

```text
src/app/shop/index.tsx
```

## 추가한 내용

### 1. 공고 등록 진입 버튼

샵 상담 목록 화면에 `새 공고 등록` 버튼을 추가했습니다.

이 버튼을 누르면:

```text
/shop/post/new
```

화면으로 이동합니다.

### 2. 공고 등록 폼

등록 화면에는 아래 입력이 들어갑니다.

- 카테고리 선택
- 샵 이름
- 서비스명
- 위치
- 상세 설명
- 지원 조건
- 가능 날짜
- 보증금

필수값은:

- 샵 이름
- 서비스명
- 위치
- 가능 날짜

로 잡아뒀고, 없으면 등록 버튼이 비활성화됩니다.

### 3. 등록 완료 화면

입력을 마치고 등록하면:

```text
/shop/post/created
```

로 이동합니다.

이 화면에서는 방금 입력한 핵심 요약값을 보여주고:

- `샵 상담 목록으로 이동`
- `새 공고 다시 등록`

버튼을 제공합니다.

## 왜 이 단계가 중요한지

지금까지는 고객이 공고를 보는 흐름과 샵이 상담을 관리하는 흐름은 있었지만, 샵이 공고를 만드는 입구는 없었습니다.

이번 단계로:

- 샵 사용자 역할
- 공고 입력 UX
- 등록 완료 흐름

의 가장 기본 뼈대가 생겼습니다.

## React 개발자 기준으로 보면

- 웹의 `create post` 폼 페이지와 완료 페이지를 라우트 두 개로 나눈 구조와 같습니다.
- RN의 `TextInput`은 웹의 `input`/`textarea` 역할을 하고, `Pressable`은 제출 버튼 역할을 합니다.
- `router.push(...)`로 등록 완료 화면으로 넘어가는 흐름은 React Router의 navigate와 거의 같은 개념입니다.

## 핵심 로직

- `/shop/post/new`는 입력값을 `useState`로 관리하는 폼 화면입니다.
- 등록 버튼을 누르면 요약값을 params로 넘기면서 `/shop/post/created`로 이동합니다.
- 즉, 이 단계에서는 아직 영구 저장보다 "등록 화면 -> 완료 화면" 흐름을 먼저 만드는 데 집중했습니다.

## 핵심 코드

```ts
router.push({
  pathname: '/shop/post/created',
  params: {
    shopName: shopName.trim(),
    service: service.trim(),
  },
});
```

등록 완료 화면은 서버에서 다시 읽는 대신, 먼저 라우터 params로 요약값을 넘겨받아 표시했습니다.
