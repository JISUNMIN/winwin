# 24. Step 18 샵 헤더 액션 추가

## 목표

샵 전용 채팅 화면 헤더에 관리자용 액션을 추가합니다.

지금까지는 샵 화면도 헤더가 고객 화면과 거의 비슷했습니다.

이번에는 샵 화면에서만:

- 현재 예약 상태
- 고객 정보 보기
- 상담 종료

액션이 보이도록 만들었습니다.

## 만든 파일

```text
src/components/winwin/ShopChatHeaderActions.tsx
```

## 수정한 파일

```text
src/components/winwin/ChatScreen.tsx
```

## 추가한 내용

샵 전용 라우트에서만 헤더 오른쪽에 아래 UI가 보입니다.

- `예약 상태` 배지
- `고객 정보` 버튼
- `상담 종료` 버튼

## 현재 동작

### 고객 정보 버튼

현재는 mock 데이터 기준으로 `Alert`를 띄웁니다.

예시 정보:

- 고객 이름
- 방문 목적
- 요청 메모

### 상담 종료 버튼

지금은 실제 종료 처리 대신, 나중에 상태 변경 로직과 연결할 수 있다는 안내 `Alert`를 띄웁니다.

## 왜 이 단계가 중요한지

샵 화면은 단순 채팅창이 아니라 상담 관리 화면에 가깝기 때문에, 헤더에서도 바로 실행할 수 있는 액션이 필요합니다.

이번 구조를 만들어두면 나중에:

- 예약 상태 직접 변경
- 고객 프로필 화면 이동
- 상담 종료 후 리스트 복귀

같은 동작을 자연스럽게 붙일 수 있습니다.
