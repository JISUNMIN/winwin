# continue-next-task

사용자가 "다음작업진행해줘", "다음 작업 진행해줘", "다음꺼 진행하자", "이어가자"라고 말하면 다음을 수행한다.

1. 프로젝트 문서와 세션 요약을 먼저 읽는다.
2. 세션 요약, 작업 기록, TODO, 설계 문서를 우선 확인한다.
3. 현재 프로젝트 상태를 파악한다.
4. 바로 다음에 해야 할 작업을 하나 정한다.
5. 필요한 파일을 확인한 뒤 작업을 진행한다.
6. 큰 변경 전에는 어떤 파일을 바꿀지 간단히 설명한다.
7. 구현 후 가능한 검증 명령을 실행하고 결과를 요약한다.
8. 작업 내용은 `codex/` 아래 md 파일에 정리한다.

우선 읽을 파일:

- `codex/SESSION_END_SUMMARY.md`
- `codex/progress-and-next-steps.md`
- `codex/README.md`
- `codex/**/*.md`
- `code/*.md`
- `code/**/*.md`
- `README.md`
- `TODO.md`
- `SESSION_SUMMARY.md`
- `WORKLOG.md`

현재 프로젝트에서 중요한 기준:

- RN/Expo 초보자에게 설명하듯 진행한다.
- 코드 변경 전에는 변경 의도를 짧게 말한다.
- 한 번에 너무 큰 기능을 만들지 않고 작은 단계로 진행한다.
- 질문 답변만 한 경우에는 md 문서를 만들지 않아도 된다.
- 실제 기능을 구현했거나 중요한 개념을 정리했으면 `codex/`에 md 문서를 추가하거나 업데이트한다.
- `codex/`와 `design-reference/`는 참고/학습용 로컬 문서로 취급한다.
